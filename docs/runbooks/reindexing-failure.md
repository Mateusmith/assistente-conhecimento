# Falha de reindexacao

1. Liste `/indices-embedding` e leia o erro sem desativar o indice `ATIVO`.
2. Valide credenciais, quota e disponibilidade do modelo de destino.
3. Uma construcao falha nunca substitui o indice ativo.
4. Corrija a causa e inicie um novo indice; preserve o anterior para rollback.

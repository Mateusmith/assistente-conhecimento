# Regressao de qualidade RAG

1. Identifique se a queda ocorreu em taxa de acerto, recall, precisao ou MRR.
2. Execute novamente o conjunto de avaliacao que disparou o alerta.
3. Compare a nova execucao com a ultima baseline aprovada pela API de comparacao.
4. Compare as estrategias hibrida, semantica e textual no endpoint de comparacao.
5. Confira fontes, filtros e versao do indice antes de ajustar limiares.
6. Reative o indice anterior quando a regressao coincidir com uma troca de modelo.
